# SuiCash ロゴ

`.opencode/skills/suicash/skill.md` のロゴ要件にもとづく。

| ファイル | 用途 |
| --- | --- |
| `suicash-logo.svg` | ワードマーク（737 B） |
| `suicash-icon.svg` | アプリ／ファビコン用 512×512、`iC` のみ（682 B） |
| `generate.py` | 上記 2 点の生成スクリプト |
| `font/suicash-wordmark.woff2` | 自前ホスト用のサブセットフォント（1.2 KB） |

どちらの SVG もグリフのパスを持たない。`<text>` で組み、Web フォントは
`@import` で Google Fonts から読み込む。

```xml
<style><![CDATA[@import url('https://fonts.googleapis.com/css2?family=REM:wght@100..900');]]></style>
<text font-family="REM" font-weight="605" style="font-variation-settings:'wght' 605">
```

`font-variation-settings` は可変フォントを解釈するブラウザでしか効かないので、
`font-weight` も併記している。これが無いと、画像ビューアや SVG エディタでは
既定ウェイト（400）で細く描画される。

## 読み込み方の注意

外部フォントを参照する SVG は、**HTML にインライン展開するか、SVG を直接開いた
ときにしかフォントが適用されない**。`<img src="...">`・CSS の `background-image`・
favicon として使うと、ブラウザが外部リソースの読み込みを遮断するため
フォールバック書体で描画される。その場合は次のいずれか。

- `generate.py` の `FONT_SOURCE = "selfhost"` にして
  `font/suicash-wordmark.woff2` を相対パスで参照する
  （外部ドメインへの依存は無くなるが、`<img>` の制約は同じ）
- 用途に応じて PNG を書き出す
- 配布用にアウトライン化する

## 組み方

`SuiCash` は `Su + iC + ash` と分解でき、Suica のロゴが `Su + iC + a` の
`iC` を白抜きにしているのと同じ位置関係になる。この `iC` だけを
「白フィル + 本文色の輪郭線」で反転させ、IC カードであることを示す。

### 1. 参照ロゴからの数値の取り方

Suica のロゴ（Wikimedia Commons の SVG）を 4000px でラスタライズし、
画素単位で以下を計測した。**パスの流用・トレースは行っていない**。

| 計測項目 | 値（キャップハイト = 1.0） |
| --- | --- |
| x-ハイト | 0.711 |
| 小文字ステムの太さ | 0.224 |
| 白抜き文字の輪郭線 | 0.062 |
| 直線の側面どうしのインク間のあき | 0.444 |
| 側面が曲線のとき 1 辺あたり詰める量 | 0.039 |

字間は実測すると `S|u` 0.429 / `u|i` 0.444 / `i|c` 0.395 / `c|a` 0.366 で、
「曲線の側面 1 辺につき約 0.039 詰める」で説明がつく。この規則を採用している。

### 2. 参照ロゴの書体の正体

参照ロゴの書体は **Humanist 970 Bold（Bitstream）** だという説がある。
これは Walter Tracy が 1959 年に Linotype & Machinery のために設計した
**Adsans** のデジタル版で、新聞の三行広告用に 4.75pt でも潰れないよう、
**アーチやボウルが縦ステムに合流する箇所でステムを削ぎ落とす**という
特徴を持つ。

参照ロゴを 6000px で拡大したところ、**この削ぎ落としが実際に存在した**。

- `u` … 右ステム下部、ボウルとの合流点に切り欠き
- `a` … ボウルと軸の合流点に切り欠き、右下に鋭い尻尾
- `S` … 終端が急角度で切られ、尖っている

一般的なグロテスクには無い特徴で、**無償の Web フォントでは再現できない**。
完全に一致させたい場合は Humanist 970 Std Bold をライセンス購入し、
`FONT_SOURCE = "selfhost"` にして `font/` に置けばそのまま使える
（字間の規則は書体に依存しない）。

### 3. 書体の選定

Google Fonts を中心に **73 書体**を集め、参照ロゴの `S` `u` `a` を
キャップハイト 200px に正規化して重ね合わせ、3 つの指標で評価した。
可変フォントは軸を座標降下法で最適化したうえで比較している。

| 指標 | 見るもの |
| --- | --- |
| 面積 IoU | 塗りつぶしの重なり具合 |
| 輪郭距離 | 輪郭どうしの対称平均距離 |
| 角重み XOR | 参照ロゴの「角らしさ」（半径 9px の円内インク率の 0.5 からの外れ）を重みにした XOR |

最初は寸法比（x-ハイト比・ステム比・字幅比）だけで選んでいたが、それでは
終端の丸めや `a` の尻尾といった**見た目を決める差**を拾えなかった。
面積 IoU も角の丸めに鈍い。最終的には角重み XOR を主指標にしている。

| 書体 | 角重み XOR | シルエット | IoU |
| --- | --- | --- | --- |
| **REM 605**（採用） | **0.6181（1 位）** | 0.2481 | S 85.2 / u 81.0 / a 85.1 |
| Mukta Bold | 0.6299 | 0.3167 | 81.9% |
| Figtree 760 | 0.6771 | 0.2319 | 81.4% |
| Asap 786 | 0.7146 | 0.2472 | 80.0% |
| Segoe UI Bold（Selawik） | 0.7667 | 0.3236 | 78.1% |
| Roboto Mono 690 | 0.8259 | 0.2757 | 75.1% |
| Helvetica Bold（Nimbus Sans） | 0.8888 | 0.3162 | 74.1% |
| Archivo Black | 1.1651 | 0.4347 | 62.9% |

ウェイトは `wght 605`。ライセンスは SIL OFL。

#### skill.md が挙げている「ブラック体の Helvetica / Segoe UI」について

skill.md は雰囲気の例としてこの 2 つを挙げているが、照合した結果どちらも
採用しなかった。

- Helvetica Bold のステム比は 0.192 で、参照の 0.224 より細い。
  太くすれば近づくのかを確かめるため、マスクを膨張させて参照とインク量を
  揃えたうえで採点した（＝ブラック体の模擬）。結果は 74.1% → **74.2%** で
  ほとんど変わらない。**太さの問題ではなく字形そのものが違う。**
  実際、ブラック体である Archivo Black は最下位だった。
- Segoe UI Bold はステム比 0.220 で参照の 0.224 とほぼ一致するが、
  x-ハイト比が 0.679（参照 0.711）と小さく、ヒューマニスト系で
  アパーチャが開いているため、シルエットの差が大きい。
  Segoe UI 本体は再配布できないため、Microsoft が OFL で公開している
  メトリック互換の Selawik で代替して計測した。

### 4. 字間

隣り合う文字の**インクの間隔**が上の規則どおりになるよう、
`<tspan x="...">` で 1 文字ずつ絶対座標に置いている。
フォント側のサイドベアリングやカーニングには依存しない。

4000px でレンダリングして実測した結果、全ペアで目標値との差は
レンダリング解像度の量子化誤差（±1px）の範囲に収まっている。

## 既知の差異・未対応

- 参照ロゴの `i` のドットは横長の矩形だが、REM のドットは丸い。
  白抜きにすると輪郭線がつくぶん目立つ。数値上の一致度は最良だが、
  この一点だけは逆方向に外れている。
- 参照ロゴが持つステムの削ぎ落とし（前述）は再現できていない。
- マスコットキャラクター（B 案 × ペンギンのキメラ）は未着手。
- 実運用にあたっては、Suica の商標との類似性について別途確認が必要。

## 再生成

```bash
python3 -m venv venv
./venv/bin/pip install fonttools brotli
./venv/bin/python assets/logo/generate.py
```

字送りの計算のために、Google Fonts から REM の可変フォントを取得する
（`TMPDIR` にキャッシュ）。

## PNG の書き出し

SVG が正本。PNG は生成物で git 管理しない（`.gitignore` 済み）。

```bash
npm --prefix assets install
npm --prefix assets run generate-png       # 2x を SVG と同名で書き出す
node assets/generate-png.mjs --scale=3     # 倍率を変える
```

ロゴの `<text>` は REM（wght 605）で描くため、スクリプトが
`REM[wght].ttf` を取得して resvg に渡す。初回のみネットワークが必要
（`TMPDIR` にキャッシュ）。手元のフォントを使う場合は
`SUICASH_REM_TTF=/path/to/REM.ttf` を指定する。
